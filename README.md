This project develops a Python-based tool to measure the cinematic impact of countries using data from IMDb: https://developer.imdb.com/non-commercial-datasets/. By combining quality and quantity metrics, it ranks and compares cinematic contributions globally. The project includes three analyses, answering following questions:  
-In which countries most of the best movies were made?  
-Which countries make unexpectedly many good movies, given other statistics of the country, such as GDP.  
-Is there a relation between quality and length of a TV series?  
This project was an assignment for the NYPD course at MIM faculty, University of Warsaw.
